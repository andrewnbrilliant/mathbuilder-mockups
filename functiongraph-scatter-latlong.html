Scatter plot with an arbitrary axis origin

FunctionGraph style · longitude × latitude · 6 US cities

The point of this example

Neither axis contains zero, and neither needs to. The axes still meet in the bottom-left corner, but that corner is (−130, 25) — a spot in the Pacific, south-west of the continental US — chosen only because it sits below and to the left of every data point on round numbers.

In the existing motion-graph mockups the corner is labelled 0 on both axes. Here it carries its real values, so nothing implies the plot has been truncated or that the corner is an origin.

A non-zero baseline is legitimate here because position, not length, carries the meaning: no mark's size is being compared, so nothing is exaggerated by starting the axis at 25°. (The zero-baseline rule applies to bars and other length-encoded marks.)

Axis setup

  • Longitude −130 to −70, ticks and labels every 10
  • Latitude 25 to 50, ticks and labels every 5
  • Corner labelled on both axes; ticks point outward; grid stays recessive
  • Arrowheads kept at the far ends only, per the existing house style

Equivalent FunctionGraph config

main =
    create
        |> withAxisX
            (axis -130 -70
                |> ticksEvery 10
                |> labelsEvery 10
                |> title "Longitude"
                |> subtitle "(degrees east)")
        |> withAxisY
            (axis 25 50
                |> ticksEvery 5
                |> labelsEvery 5
                |> title "Latitude"
                |> subtitle "(degrees north)")
        |> withPoints
            [ point -122.33 47.61 |> customPointLabel "Seattle"
            , point -118.24 34.05 |> customPointLabel "Los Angeles"
            , point -104.99 39.74 |> customPointLabel "Denver"
            , point  -95.37 29.76 |> customPointLabel "Houston"
            , point  -87.63 41.88 |> customPointLabel "Chicago"
            , point  -74.01 40.71 |> customPointLabel "New York"
            ]
        |> embed

Untested — written from the package API, not compiled. Only one example in FunctionGraph V0 currently uses an axis range that excludes zero (axis 1 7), and none has both axes excluding it, so the rendering above is a proposal rather than observed behaviour.
